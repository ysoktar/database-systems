NULL kuralları

  • Karşılaştırma NULL içeriyorsa → UNKNOWN.
  • AND: FALSE baskın; OR: TRUE baskın; NOT UNKNOWN = UNKNOWN.
  • WHERE / HAVING / ON yalnızca TRUE'yu tutar.
  • NOT IN listesinde NULL varsa → hiçbir satır.
  • COUNT(*) satır sayar; COUNT(A), SUM, AVG, MIN, MAX NULL'ları atlar.
  • Boş kümede COUNT = 0, diğerleri NULL.
  • GROUP BY'da NULL'lar tek bir grup oluşturur.
  • Iç join'de NULL join sütunu eşleşmez.

Sorgu kalıpları

-- "every Y" (division): no Y that x is not related to
SELECT … FROM X x
WHERE NOT EXISTS (SELECT * FROM Y y
                  WHERE NOT EXISTS (SELECT * FROM R r
                                    WHERE r.x = x.id AND r.y = y.id));

-- "no related row" (anti-join)
SELECT … FROM X x WHERE NOT EXISTS (SELECT * FROM R r WHERE r.x = x.id);
SELECT … FROM X x LEFT JOIN R r ON r.x = x.id WHERE r.x IS NULL;

-- the maximum within each group
SELECT … FROM T t
WHERE t.v = (SELECT MAX(u.v) FROM T u WHERE u.g = t.g);

-- count including zero
SELECT x.id, COUNT(r.x) FROM X x LEFT JOIN R r ON r.x = x.id
GROUP BY x.id;

-- groups whose members satisfy something overall (Q28)
… WHERE cond AND g IN (SELECT g FROM T GROUP BY g HAVING …)

DDL ve güncelleme

CREATE TABLE T ( A INT NOT NULL DEFAULT 0 CHECK (A > 0),
                 B VARCHAR(20) UNIQUE,
                 C CHAR(9),
                 CONSTRAINT TPK PRIMARY KEY (A),
                 CONSTRAINT TFK FOREIGN KEY (C) REFERENCES S(Id)
                   ON DELETE {CASCADE | SET NULL | SET DEFAULT | NO ACTION} ON UPDATE CASCADE );
ALTER TABLE T ADD COLUMN D DATE;          ALTER TABLE T DROP COLUMN D {CASCADE | RESTRICT};
ALTER TABLE T ALTER COLUMN A SET DEFAULT 1;  ALTER TABLE T DROP CONSTRAINT TFK;
DROP TABLE T {CASCADE | RESTRICT};        DROP SCHEMA S CASCADE;
INSERT INTO T (A, B) VALUES (1, 'x');     INSERT INTO T SELECT …;
UPDATE T SET A = A + 1 WHERE …;           DELETE FROM T WHERE …;

CREATE ASSERTION N CHECK (NOT EXISTS (SELECT … violating rows …));
CREATE TRIGGER N {BEFORE | AFTER} {INSERT | UPDATE [OF cols] | DELETE} ON T
  FOR EACH ROW WHEN (cond) <action>;

Kitap (standart SQL) ve MySQL. Yukarıdakiler kitabın sözdizimidir; sınavda bunu yazın. Sitedeki kutular MySQL'de çalıştığı için şu farkları görürsünüz:

  • Metin birleştirme CONCAT(a, b); MySQL'de || OR demektir.
  • FULL OUTER JOIN yok: LEFT JOIN … UNION … RIGHT JOIN.
  • CREATE ASSERTION, CREATE DOMAIN, DEFERRABLE yok; InnoDB ON DELETE SET DEFAULT'u kabul etmez.
  • DROP … RESTRICT / CASCADE yazılabilir ama yok sayılır; foreign key ile başvurulan tablo hiç silinemez. Foreign key'i kaldırmak: ALTER TABLE T DROP FOREIGN KEY TFK.
  • Trigger tek bir olaya bağlanır, WHEN yoktur: koşul gövdede IF … THEN … END IF; bir işlemi reddetmek için SIGNAL SQLSTATE '45000'. Gövde DELIMITER // ile yazılır.
  • Gruplanmamış sütun hatası 1055; karşılaştırmalar varsayılan olarak büyük/küçük harfe duyarsız ('smith' = 'Smith').
