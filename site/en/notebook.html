Notebook exercises

The ten exercises of the class notebook Exercises — Chapters 6 and 7, from easy to hard: ★☆☆ easy (Ch 6), ★★☆ medium and ★★★ hard (Ch 7). No Colab or Docker needed: MySQL runs on this page.

Answers are checked exactly as in the notebook. The result of the last query in the box is compared with the exercise's expected answer, and you get ✔ Correct, or ✘ with what is wrong: the number of columns, the number of rows, the values or the order. Column names do not matter, numbers are compared to two decimals, and row order matters only if the exercise asks for it. As in the notebook, the expected answers are stored only as fingerprints (hashes).

Your answers and progress are saved in this browser (they survive closing the page). If an exercise changes the data (e.g. you tried an UPDATE), the box's Reset database brings COMPANY back to its starting data.

The notebook was written for PostgreSQL; this page runs the same exercises on MySQL. The checker looks only at the rows of the result, so a correct query is accepted in both places. Mind the syntax differences: MySQL concatenates text with CONCAT(a, b) (not ||) and has no FULL OUTER JOIN; WITH RECURSIVE, EXCEPT and INTERSECT exist in MySQL 8.
