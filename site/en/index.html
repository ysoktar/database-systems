How do the topics connect?

A database project goes in this order, and so does the book:

  1. Requirements → conceptual schema (Ch 3–4). Sentences like "every employee works for a department" become an ER/EER diagram: entities, relationships, cardinality and participation constraints.
  2. Conceptual schema → relational schema (Ch 5, the mapping in Ch 9). Entities and relationships become tables, keys become primary and foreign keys; integrity constraints protect the data.
  3. Relational schema → SQL (Ch 6–7). CREATE TABLE defines the schema; SELECT queries it, INSERT/UPDATE/DELETE change it; views, triggers and assertions add further rules.
  4. Underneath it all, the DBMS (Ch 1–2). The three-schema architecture and data independence keep programs safe from schema changes.

How to use the site

SQL boxes

Change the query in a box and press ▶ Run (or Ctrl+Enter). The first run downloads the MySQL engine into your browser (≈ 23 MB, cached afterwards).
