Relational algebra (preview)

Ch 8 is not on the midterm. This page briefly introduces the formal language behind the SQL of Ch 6–7: every algebra operation has an SQL equivalent, and all of them can be run below.

Relational algebra is a procedural language of operations on relations: each operation takes one or two relations and returns a new relation (closure). The operations work with set semantics: a result has no duplicates. SQL uses multiset semantics.

σ is commutative (σc1(σc2(R)) = σc2(σc1(R))); π removing duplicates corresponds to SQL's DISTINCT.

SELECT DISTINCT Sex, Salary FROM EMPLOYEE;

Set operations

∪ (UNION), ∩ (INTERSECTION), − (MINUS/DIFFERENCE): the two relations must be type compatible (union compatible). × (CARTESIAN PRODUCT) combines every pair of tuples.

-- DEP5_EMPS ← σ_{Dno=5}(EMPLOYEE); RESULT1 ← π_{Ssn}(DEP5_EMPS); RESULT2 ← π_{Super_ssn}(DEP5_EMPS)
-- RESULT ← RESULT1 ∪ RESULT2
SELECT Ssn FROM EMPLOYEE WHERE Dno = 5
UNION
SELECT Super_ssn FROM EMPLOYEE WHERE Dno = 5;

-- SSN_PNOS   ← π_{Essn, Pno}(WORKS_ON)
