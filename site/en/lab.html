SQL lab

Write any SQL you like on COMPANY: queries, DDL (CREATE, ALTER, DROP), updates, views, triggers, transactions. Separate statements with ;; each result gets its own table.

Schema browser

Read live from the MySQL catalog (information_schema): create a table or add a column and it shows up here. Underlined: primary key; blue: foreign key.

Good to know. The database lives only in this tab: reloading the page brings COMPANY back to its starting state (the text you typed in the console is kept). The tables are in the company database (in MySQL "schema" and "database" mean the same thing), and a demo database is ready for test tables: CREATE TABLE demo.T (…). The engine is the MySQL-compatible go-mysql-server compiled to WebAssembly: its syntax, error numbers and information_schema are like MySQL 8's. A few features are missing: you cannot update through a view, and EXPLAIN output looks different from real MySQL's. The pages concerned say so.
